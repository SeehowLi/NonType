# Upstream provenance

NonType is an independent derivative of tover0314-w/opentypeless, inspected at commit 213d4c4d78e398aad2e6b85e86d61dad59dc7387. Original MIT copyright and Git history are retained. The implementation keeps Tauri 2 / Rust / React and reuses audio capture, providers, storage, shortcuts and output components.

Protocol reference: aibox22/opentypeless at eea4190ad277686f7060a4e722a5b63363c14adf (see its upstream history for the current revision). The project does not repackage that Electron application.

NonType's entry point exposes local Doubao speech/Ark settings, personal vocabulary, history and user-editable cleanup instructions. Upstream cloud/account/subscription modules may remain as unmounted source; NonType does not operate the original vendor backend or inherit any signing credentials, hosting or support service. Upstream multilingual README files and older documentation describe upstream releases, not the NonType feature set.
